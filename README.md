# Шахматная сетка

Мобильное React-приложение для одного шахматного турнира **до двух поражений**. React + Vite + TypeScript + Tailwind; работает полностью в браузере, сохраняет сетку в `localStorage`, формирует сжатую ссылку для просмотра и не требует сервера или регистрации.

## Правила и сетка

- 20 участников начинают с 10 настоящих матчей. В каждом следующем раунде нечётный участник получает автоматический проход без поражения.
- Победитель верхней сетки остаётся в верхней. Проигравший переходит в нижнюю.
- В нижней сетке поражение становится вторым и завершает участие.
- Победители верхней и нижней сеток играют общий финал. Если выигрывает финалист нижней, открывается ещё один решающий матч: оба теперь имеют по одному поражению.
- Третье место получает проигравший финала нижней сетки (при двух участниках третьего места нет).
- Ничья требует победителя тай-брейка. Смена победителя сбрасывает зависимые результаты обеих сеток и финала после подтверждения.
- Старые сохранения на вылет и старые ссылки продолжают открываться. Кнопка «Перестроить сетку» сохраняет состав, но после подтверждения сбрасывает результаты и создаёт новый формат.

В карточках показаны постоянный номер игрока, счёт, статус, источник участника и следующий матч. Выбор «Путь игрока» подсвечивает его карточки и сыгранные переходы. На телефоне — вкладки веток и раундов; на компьютере — линии между матчами и прокрутка внутри сетки.

Ссылка — **снимок**, а не онлайн-трансляция. После новых результатов отправьте новую ссылку. Для открытия на другом устройстве используйте опубликованный сайт: `localhost` доступен только на устройстве организатора. Для очень больших снимков QR может не вместить данные; копирование полной ссылки остаётся доступным.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес (обычно `http://localhost:5173`).

Используйте Node.js 24.13+ и `npm ci` для воспроизводимой установки из `package-lock.json`.

## Проверка и production-сборка

```bash
npm test
npm run build
npm run preview
```

Готовые статические файлы появятся в папке `dist`.

## Проверка интерфейса в Chrome

При работающем `npm run dev` в другом терминале:

```bash
npm run test:browser
```

Тест запускает отдельный Chrome с временным профилем, проверяет ширины 360, 375, 390, 414, 430, 768 и 1440 px, обе темы, полный турнир на 20 человек, тай-брейк, нижнюю сетку, исправление результатов, перезагрузку, просмотр ссылки в чистом браузерном контексте, восстановление и решающий финал. Скриншоты сохраняются в `.qa/` (не входят в production).

По умолчанию используется Windows-путь Chrome. Для другого окружения задайте `CHROME_PATH` до исполняемого файла и при необходимости `TEST_URL` (по умолчанию `http://127.0.0.1:5173`). Браузер дополнительно скачивать не нужно.

## Деплой

### Vercel

1. Импортируйте репозиторий в Vercel.
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.

### Netlify

1. Создайте сайт из репозитория.
2. Build command: `npm run build`.
3. Publish directory: `dist`.

Приложение использует query-параметр для снимка турнира, поэтому отдельные SPA redirects не требуются.
